## 📝 Notes
- Python decides a variable's type automatically. Use `type(x)` to check it.
- Lists keep order and use positions (`topics[0]`); dicts look things up by key (`student["name"]`).
- Functions stop you from repeating code. ML code is mostly functions working together.
- NumPy applies math to a whole array at once. That's why ML libraries are built on it.
- pandas is for tables. In real projects, you look at the data with pandas before any modeling.

Run any script: `python 04_numpy_intro.py`
